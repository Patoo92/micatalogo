  2. SEGURIDAD
================================================================================

  2.1 Implementado ✅
  ─────────────────────────────────────────────────────────────────────
  - CSP nonce en scripts (generado en init_session.php)
  - CSRF tokens en todos los formularios POST
  - Rate limiting: login (5/15min), registro (3/15min), slug lookup
    (30/15min), API (60/min)
  - Password hashing con PASSWORD_BCRYPT
  - Regeneración de session ID tras login
  - Session cookie: httponly=true, samesite=Strict
  - Prepared statements en TODAS las consultas SQL
  - Headers: X-Frame-Options (DENY), X-Content-Type-Options (nosniff),
    Referrer-Policy
  - Uploads: validación MIME real con finfo, tamaño máximo 2MB,
    .htaccess en imagenes/ y uploads/ bloquea *.php
  - Configuración sensible fuera del webroot (micatalogo-config/)

  2.2 Bugs de seguridad a corregir (ALTA prioridad)
  ─────────────────────────────────────────────────────────────────────

  #1  cambiar-password.php:27
      La validación EXIGE mayúscula [A-Z] y número [0-9], pero
      registro.php acepta passwords sin esas reglas (solo min 10 chars).
      Usuarios con password tipo "abcdefghij" no podrán cambiarla.

  #2  templates/catalogo.php:144, producto.php:96,168
      codigo_tracking y css_personalizado se imprimen con echo RAW
      (<?= $tienda['codigo_tracking'] ?>).
      Stored XSS contra visitantes del catálogo público.

  #3  init_session.php:10
      Session cookie Secure flag depende de HTTPS detectado.
      Si el servidor no fuerza HTTPS, la cookie viaja en texto plano.

  #4  logout.php, logout-admin.php
      No verifican CSRF. Ataque de Logout CSRF posible (daño bajo).

  #5  api.php:13
      CORS devuelve "*" cuando no hay Origin header.
      Permite peticiones cross-origin desde local filesystem.

  2.3 Mejoras de seguridad (MEDIA prioridad)
  ─────────────────────────────────────────────────────────────────────
  - .htaccess: agregar HSTS (Strict-Transport-Security)
  - .htaccess: agregar CSP como fallback (si PHP falla antes de
    conexion.php, no hay CSP)
  - index.php:71,77 y admin.php:62 usan LIMIT $x OFFSET $y con (int)
    cast en vez de placeholders PDO
  - Sin timeout de sesión por inactividad
